# Bundled fonts

These TrueType files are embedded into exported PDFs by mPDF (see
`App\Services\BookExportService`, which registers this directory as an mPDF
`fontDir`). They are bundled rather than downloaded at runtime so that PDF
export is deterministic and works offline.

commercial or not, on two conditions that this directory satisfies:

1. each copy ships the copyright notices and the license text (`OFL.txt`), and
2. the fonts are not sold on their own, and stay under the OFL.

That last point matters: **the fonts are not covered by the project's MIT
license.** They remain OFL-licensed for anyone who receives a copy of this
repository — the OFL requires fonts stay under the OFL, so they cannot be
relicensed under MIT along with the rest of the code.

Each family ships a Regular and a Bold static instance as
`<prefix>-Regular.ttf` / `<prefix>-Bold.ttf`. Those filenames are generated by
`BookFont::mpdfFontData()`, so adding a family means dropping both weights here
and adding a case to `App\Enums\BookFont`.
